# Product Sales Dataset – Data Analysis

## 📌 Project Overview
This dataset contains product sales information, including product IDs, product names, brand names, prices, quantities, categories, price ranges, and date-related details.

The main objective is to explore product information, analyze pricing patterns, and understand product distribution across different categories and countries.

## 📊 Dataset Description

The dataset contains 10 columns:

| Column Name | Description |
|---|---|
| Product ID | Unique identification of each product |
| Product Name | Name of the product |
| Brand Name | Brand associated with the product |
| Price ($) | Price of the product in US dollars |
| Quantity | Number of units |
| Category | Product category |
| Price Range | Classification based on product price |
| Day | Day extracted from Product ID |
| Country Code | Country identification code |
| Month | Month extracted from Product ID |

## 🎯 Project Objectives

- Determine the total number of products.
- Calculate the average product price.
- Identify the highest and lowest product prices.
- Calculate the total product quantity.
- Analyze brand-wise product distribution.
- Explore category-wise product distribution.
- Classify products based on price ranges.
- Perform country-wise analysis.
- Perform month-wise analysis.
